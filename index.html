SFR-AutoR&D

What if an AI agent could take an R&D goal, discover a new algorithm or method, implement it, run controlled experiments, and keep only what actually works? That’s what we’re building at Salesforce AI Research: specialized R&D agents that go beyond fixing code or optimizing implementations. They form hypotheses, invent new methods, test competing ideas, and validate improvements through evidence. Research discovers what is new; development turns what is proven into something real. The agents connect the two through a continuous loop of algorithmic discovery, experimentation, verification, and refinement. The goal is a tighter loop from scientific discovery to verified engineering progress.

Two questions for autonomous R&D

01 / Code

Given a goal on production code, can an agent reach it, and prove it?

SFR-AutoR&D-EngineerView page ↗

Point it at a codebase and give it a goal: fit a training run in memory, raise throughput, cut latency, keep a pipeline stable. It studies the system, invents its own ideas, runs controlled experiments, and keeps only the changes that reach the goal with evidence. Seven verified results so far across pandas, USearch, hnswlib, and the SFR-RL stack.

TestExact output equality on every change, and paired measurements with confidence bounds.
02 / Models

Can an agent train a better model, and verify it?

SFR-AutoR&D-TrainForgeView page ↗

Give it a baseline model and a target. It designs the data, tools, training, and evaluation, writes and validates the code, runs the experiments, and returns the best verified checkpoint. Four training programs are in progress.

TestHeld-out evaluation bound to the checkpoint that produced it. Weak evidence keeps the incumbent.
How SFR-AutoR&D works

One loop, two targets.

The loop is the same whether the target is an engineering goal on a production codebase or a model and its benchmark. Only the gates change shape: exact output checks for code, held-out evaluation for models.

01
ScopeScope the targetStudy the system and measure the gap between where it stands and the goal.
02
ProposePropose ideasGenerate many candidate changes, like a researcher working through a hypothesis list.
03
BuildBuild and runImplement each idea and run it against the unmodified baseline in a sandbox.
04
VerifyVerify and measureCorrectness gates and statistics with confidence bounds decide what is real.
05
PromotePromote or preserveA vetted artifact ships with its evidence. Anything weaker keeps the incumbent.
↺Only candidates that clear every gate become artifacts. The rest loop back as recorded lessons for the next hypothesis.

Implications

What this means in practice

An SFR-AutoR&D agent returns artifacts: a working patch or a verified checkpoint, bundled with the benchmark record, the correctness checks, and the analysis that justify it. A reviewer can read the evidence before the code, and a maintainer can rerun it.
